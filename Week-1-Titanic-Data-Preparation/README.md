# Week 1 – Titanic Dataset: Data Preparation & Cleaning

## Project Overview

This project was completed as part of the **Data Analytics Internship Program (Week 1)**.

The objective of this project was to inspect, clean, and prepare the Titanic dataset by identifying common data quality issues and applying appropriate preprocessing techniques to make the dataset ready for future analysis.

---

## Project Objectives

- Import and inspect the dataset
- Explore the dataset structure
- Identify data quality issues
- Handle missing values
- Detect duplicate records
- Verify data types
- Improve column readability
- Prepare a clean dataset for future analysis

---

## Data Preparation Steps

### 1. Dataset Exploration

- Loaded the dataset
- Inspected rows and columns
- Reviewed dataset structure
- Generated descriptive statistics

### 2. Data Quality Assessment

- Identified missing values
- Checked duplicate records
- Verified data types

### 3. Data Cleaning

- Filled missing values in the Age column using the median
- Filled missing values in the Embarked column using the mode
- Removed the Cabin column due to a high percentage of missing values
- Renamed selected columns for better readability

### 4. Final Verification

- Confirmed that no missing values remained
- Verified the final dataset structure
- Exported the cleaned dataset
